# BozorPlus — Milliy Professional Elektron Savdo Platformasi

O'zbekiston bozori uchun to'liq moslashtirilgan, interaktiv mahsulotlar katalogi, qidiruv, savatcha, to'lov simulyatsiyasi, sotuvchi kabineti va kuchli admin boshqaruv paneliga ega zamonaviy marketplace ekotizimi.

## Ishga tushirish

Fayl mutlaqo mustaqil (self-contained) bo'lib, tashqi kutubxona yoki API kalitlarisiz brauzerda to'liq ishlaydi. index.html faylini brauzerda ikki marta bosib ochish yoki 'python -m http.server 8000' buyrug'i orqali mahalliy serverda ishga tushirish mumkin.

`python -m http.server 8000`
